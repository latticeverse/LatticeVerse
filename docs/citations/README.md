# LatticeVerse citations

Each project has a separate citation file so that a paper, software release, or future dataset can be cited without copying metadata into the main README. Citation keys are unique within this directory, and DOI values use the bare DOI form.

Use the paper entry for scientific claims. Add a software or dataset entry to the project file when a citable release is published. Files that contain only a `citation pending` note are placeholders for projects whose canonical publication metadata is not public yet.
